Ils sont archivés le 25 septembre 2026 et conservés tels quels, comme trace des décisions de revue ([`REVUE_TECHNIQUE.md`](../REVUE_TECHNIQUE.md), axe l). Seuls les chemins qui pointent vers d'autres fichiers archivés ont été mis à jour.

Ces fichiers ne décrivent plus l'état actuel : les chemins d'abonnement et le `GET /api/auth/me` qu'ils mentionnent ont changé depuis. L'état courant est dans [`DOCUMENTATION_TECHNIQUE.md`](../DOCUMENTATION_TECHNIQUE.md) et [`RAPPORT_DE_TESTS.md`](../RAPPORT_DE_TESTS.md).
